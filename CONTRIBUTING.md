# Contributing to CritMAT

Thank you for your interest in contributing to CritMAT!
We are looking for collaboration to incorporate new data sources or assessments

## Reporting Issues

If you encounter a bug or unexpected behavior:

- Search existing [issues](https://github.com/meyerdata/CritMAT/issues) to avoid duplicates
- Open a new issue with a clear title and description
- Include your Python version, operating system, and steps to reproduce the problem
- If the issue is data processing related provide detailed information about the used input file
- Attach relevant log output or error messages if applicable

## Suggesting Features

We welcome suggestions for new data sources, caluculations, features or improvements:

- Open a [feature request issue](https://github.com/meyerdata/CritMAT/issues/new?labels=enhancement)
- Describe any new data sources, calculations or features you suggest
- Describe why it would be useful

## Questions

For general questions, open a discussion in the [GitHub Discussions](https://github.com/meyerdata/CritMAT/discussions) page or contact us directly.
