## World Governance Indicators

Source: World Bank Group
URL: https://www.worldbank.org/en/publication/worldwide-governance-indicators

### File Naming Convention
- Expected: `wgidataset_with_sourcedata-2025.xlsx`
- Pattern: `wgidataset_with_sourcedata-{year}.xlsx`
- The year represents the publish year of the dataset

### Expected Structure
- Format: Excel (.xlsx) with multiple sheets
- Each sheet contains one governance dimension
