The British Geological survey provides a API connection for data access:
https://ogcapi.bgs.ac.uk/
The ouput csv files of the API should be put into this directory.

## British Geological Survey

Source: British Geological Survey
URL: https://ogcapi.bgs.ac.uk/

### File Naming Convention
- Output CSV files from the BGS API should be placed in this directory
- No specific naming pattern required

### Expected Structure
- Format: CSV files from BGS OGC API
- Files contain: bgs_commodity_trans, bgs_sub_commodity_trans, quantity, units, year, country_iso2_code
