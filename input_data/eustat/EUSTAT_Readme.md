## Eurostat International Trade Data

Source: Eurostat European Commission
URL: https://ec.europa.eu/eurostat/databrowser/bulk?lang=en&selectedTab=fileComext&breadcrumbFilter=COMEXT_DATA%2FPREFERENCES

### File Naming Convention
- Expected: `tariff_{year}52.dat` (e.g., `tariff_202052.dat`)
- 52 indicates week 52 (year-end data)

### Expected Structure
- Format: Tab-separated values (.dat)
- Files contain: PERIOD, PRODUCT, REPORTER, PARTNER, QUANTITY_KG, VALUE_EUR
