## World Mining Data

Source: Austrian Federal Ministry of Finance
URL: https://www.world-mining-data.info/

### File Naming Convention
- Expected: `6.4.Production of Mineral Raw Materials of individual Countries by Minerals.xlsx`
- Must contain the "6.4." prefix

### Expected Structure
- Format: Excel (.xlsx) with multiple sheets
- Each sheet represents a different material
- Skiprows: 1 (header row)
