## United States Geological Survey - Mineral Yearbook

Source: United States Geological Survey (USGS)
URL: https://www.usgs.gov/centers/national-minerals-information-center/commodity-statistics-and-information

### File Naming Convention
- Files must be XLSX format (not XLS)
- Year extracted from filename (e.g., `myb1-2023-nickel-ERT.xlsx`)
- Pattern: `myb1-{year}-{material}.xlsx`

### Expected Structure
- Place files in material-specific subfolders
- Files contain production data with multiple sheets
- Each sheet represents a category (mining/refining)
